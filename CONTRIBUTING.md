# Contributing

Please propose a bounded change through an issue or pull request. Include the Lean/Python version, the source commit when analyzing external projects, a minimal reproduction, and tests.

Always distinguish observed facts from heuristic candidates. Do not make mathematical correctness claims from LPAF outputs. Third-party Lean sources are not automatically under the Unlicense; avoid copying them into this repository without permission or confirmed compatible licensing.

Code style: standard-library Python with type hints where useful. Add or update unit tests for bug fixes, especially for provenance and source-location regressions.
